# ADR 0010 — Catalogue local et signaux de sortie

> Partiellement remplacé par [ADR 0021](0021-responsabilites-fournisseurs.md) pour les responsabilités fournisseurs.

Le catalogue partagé est créé par les favoris réellement rencontrés. Les fournisseurs autorisés complètent ensuite l’identité locale selon le type d’œuvre. Une réponse est mise en cache dans PostgreSQL avec provenance.

Les annonces AniList ne prouvent jamais une disponibilité. Les connecteurs des pages favorites constatent séparément les releases et créent les origines utilisateur.
