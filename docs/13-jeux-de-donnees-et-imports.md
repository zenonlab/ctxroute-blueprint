# Données et imports

Les catalogues AniList et MangaUpdates ne sont pas alimentés par un dump. Les données externes sont obtenues à la demande uniquement pour les œuvres réellement rencontrées : AniList pour les anime et les images, MangaUpdates pour manga/manhwa/manhua.

Les fixtures de test sont synthétiques et ne constituent pas une source de production. Tout import futur nécessiterait une nouvelle décision de contrat ; aucun endpoint d’import global n’est actif.
