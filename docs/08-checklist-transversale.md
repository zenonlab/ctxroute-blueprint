# Checklist transversale

- [ ] les politiques versionnées `anilist` et `mangaupdates` existent et limitent leurs finalités ;
- [ ] MangaUpdates est le seul fournisseur canonique des œuvres de lecture ;
- [ ] AniList est le seul fournisseur canonique des anime ;
- [ ] la progression personnelle ne provient jamais d’un fournisseur catalogue ;
- [ ] aucune migration historique n’est exécutée ;
- [ ] aucun dump ou préchargement global n’est lancé ;
- [ ] les ambiguïtés restent en revue ;
- [ ] une œuvre locale reconnue reste visible pendant un échec ou une ambiguïté fournisseur ;
- [ ] couverture et bannière ont des validations indépendantes ;
- [ ] aucun reset, worker, migration ou purge automatique ne supprime un asset image ;
- [ ] les routes d’images vérifient le lien utilisateur ;
- [ ] l’extension est réappairée et resynchronisée après reset ;
- [ ] lint, types, tests, build et smoke Docker passent.
