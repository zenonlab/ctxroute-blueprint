# Architecture Decision Records

Create an ADR for durable architecture, contract, security, dependency, or major constraint decisions. Name each file with a four-digit sequence and a short description.

Accepted ADR meaning is immutable. Replace a decision with a new ADR that
declares `supersedes`, then add only `superseded-by` and status `superseded` to
the old ADR. Use `editorial-correction: true` only for non-normative edits;
`scope`, `contracts`, `Decision`, `Consequences`, and status remain unchanged.

Durable decisions are required for architecture, contracts, security, dependencies, and major constraints.
