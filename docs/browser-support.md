# Browser support evidence

Date: 2026-09-05

## Support target

Tobirink targets current stable Chromium and Firefox with separate WXT
Manifest V3 builds. Both packages contain the popup, options, library, Review
and agenda surfaces.

## Generated platform differences

| Capability | Chromium package | Firefox package |
| --- | --- | --- |
| Background | module `service_worker` | module `scripts` entry |
| Popup | `action.default_popup` | `action.default_popup` |
| Settings | `options_ui.open_in_tab` | `options_ui.open_in_tab` |
| Signing metadata | store-assigned ID | stable Gecko ID `tobirink@tobirink.local` |
| Data declaration | no host permissions | no host permissions and `required: [none]` |

These differences are generated by WXT from one source configuration. Product
components do not branch on a browser name.

## Verified in this environment

- `npm run build:extension` and `npm run build:extension:firefox` generate all
  six declared entrypoints for both targets.
- `npm run test:security` validates both generated manifests, their local-only
  CSP, permission allowlist, empty host permissions and Firefox metadata.
- `npm run test:e2e` passes the 53 shared extension contract and vertical-flow
  tests.

## External browser pass still required

No manual compatibility claim is made for this session. Google Chrome is
installed, but the connected browser controller reports `No browser is
available`. Firefox and the optional `web-ext` validator are not installed.
Adding that dependency was not part of the approved step, so the repository
was not expanded silently.

Before release, run the packaged extension in current stable Chrome and Firefox
and record extension-menu launch, header navigation, Review bell/popover, candidate
selection and skip, library progress, agenda, settings, offline
degradation and background restart. Then run `web-ext lint` against the fresh
Firefox output and expose that check as `npm run test:firefox`.

[Firefox browser-specific settings](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/browser_specific_settings),
and [Firefox built-in data consent](https://extensionworkshop.com/documentation/develop/firefox-builtin-data-consent/).
