# Security policy

## Supported versions

Only the latest revision of the `main` branch is supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting for this repository and include reproduction steps,
impact, and any known mitigation.

Repositories generated from this template must enable their own private
reporting channel and replace this section with project-owned contact details.
If the private reporting button is unavailable, open an issue containing no
vulnerability details and ask the maintainers for a secure contact method.

Security reports should receive an initial acknowledgement within seven days.
